About Me

I am completing a Bachelor of Science in Cyber Engineering Technology at A&M University San Antonio (expected May 2027), and I also hold an associate degree in General Science from Houston City College.

I chose cybersecurity because it is an ever-evolving landscape where the dangers grow right alongside it. Phishing, malware, hacking and countless other attacks keep changing, and I want to understand how it all works so I can help build proper defenses against it. My goal is to make a positive impact on this new landscape.

Along the way I have delved into cybersecurity through projects including CTFs, Penetration Testing, Threat Intelligence using Nmap, reverse engineering with Ghidra, and real-time simulation of attacks and defense through VM systems and test frameworks like Metasploit. My work also includes hunting stealthy, fileless malware through memory forensics, designing a privacy-preserving layer for large-scale data pipelines using differential privacy, and building a tool that detects malicious permission escalation in Android applications. I also enjoy researching artificial intelligence and how its capabilities can be applied across different areas of cyberspace.

Most recently, I worked as a remote Cyber Security Basics intern with Tomorrow's Leaders Today (TLT). In a small team, I researched threat intelligence, OSINT and phishing attack vectors, wrote technical reports, and collaborated with other cybersecurity groups through peer review to solve the questions we were given.

Alongside security, I love the creativity that comes with programming. With Python and JavaScript I can build websites, applications, games and widgets, with full-blown interactivity and APIs for a majority of common website use cases, and I can even go as far as programming electrical parts to create something physical. One example is Championship-Rounds, a full-stack mock betting platform for an MMA fight card that I built and deployed with Node.js and MongoDB. That blend is why I am drawn to Secure Software Development: a career that combines security with creativity.

Outside of tech, you will usually find me weightlifting, playing soccer, playing video games, or traveling.

I want to put my skills to work so that I can begin creating a safer, more immersive digital environment for the world to enjoy! I look forward to connecting with you.

Projects

Differential Privacy for Large-Scale Data Mining Using AI

Big Data course project

Explored how adding controlled statistical noise protects individuals in large datasets against linkage attacks, drawing on real cases like the Census Bureau reconstruction attack. I built an AI benchmark on the 1994 US Adult Census data that predicts income while injecting Gaussian noise, then charted the trade-off between privacy budget and accuracy. A live pipeline on Hadoop and Spark processed streamed entries and applied the noise in real time.

  • Python
  • Apache Spark
  • Hadoop
  • diffprivlib
  • Differential Privacy

Memory Forensics and Volatile Data Analysis

Computer Forensics course project

Staged a fileless malware attack in a lab, where a Kali Linux machine delivered a Meterpreter payload through reflective DLL injection into a Windows 11 virtual machine. I captured the victim's RAM and analyzed it in a SIFT workstation with Volatility 3, where malfind exposed injected, executable memory regions that a standard module listing hid completely. Reviewed current research on why memory-only threats evade traditional detection.

  • Volatility 3
  • Metasploit
  • SIFT Workstation
  • Magnet RAM Capture
  • Kali Linux
View the PowerPoint View on GitHub

Real-Time Detection of Malicious Permission Escalation in Android

Wireless & Mobile course project

Built a monitoring pipeline that watches what an Android app actually does and compares it to what it declared. Frida hooks track API calls in real time while an extraction script decodes the APK's permissions. A comparison engine then flags permission goldmining and confused deputy attacks, which it caught in a purpose-built test app and rated critical, while a clean app from F-Droid stayed quiet.

  • Frida
  • Python
  • Android Studio
  • Mobile Security
  • APK Analysis
